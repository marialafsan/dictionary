

# Dictionary

This project implements a Java-based translation dictionary that maps words to their translations in other languages, using hashmaps to allow for an easier search, through a clean text-based user interface.


## Documentation

📖 [Javadoc](https://marialafsan.github.io/dictionary/)


## Why

**Hands-on project** built to practice and demonstrate:

- **Object-oriented programming** (classes and objects)
- A simple **user interface implementation**
- Working with **hashmaps** for data storage and retrieval
- **Version control** using Git and GitHub
